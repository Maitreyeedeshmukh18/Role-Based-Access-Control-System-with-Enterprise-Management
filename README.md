# Role-Based-Access-Control-System-with-Enterprise-Management
Project Overview
This project is a Role-Based Access Control (RBAC) System with enterprise management built using the MERN stack — MongoDB, Express.js, React.js, and Node.js.
It enables secure access to different modules (Users, Employees, Enterprises, Products, and Dashboards) based on assigned roles and permissions.
Admins can manage enterprises, employees, users, and define roles with specific access rights. Regular users can only view or modify data according to their assigned permissions.

Technologies
•	Frontend: React.js + Tailwind CSS
•	Backend: Node.js + Express.js
•	Database: MongoDB Atlas(Mongoose)
•	Auth: JWT (JSON Web Tokens)
•	Testing: Postman / Crytool

To run frontend:-
1.	cd frontend
2.	npm run dev
3.	Connects to backend APIs (http://localhost:5000/api/...)
4.	Local:   http://localhost:5173/

To run Backend:-  
1.	cd Backend
2.	npm install express, mongoose, bcryptjs, jsonwebtoken, cors, dotenv, nodemon.
3.	nodemon server.js
